# CodeAlpha — Phishing Awareness & Security Training

An interactive web-based cybersecurity training module designed to educate users on recognizing social engineering tactics, email red flags, fake websites, and modern phishing schemes.

Developed as part of the **CodeAlpha Cyber Security Internship** (Task 2).

---

## 🎯 Learning Objectives & Highlights
1. **Attack Vectors**: Detailed breakdown of Email Phishing, Spear Phishing, Whaling (BEC), Smishing, Vishing, and Clone Phishing.
2. **Interactive Email Inspector**: Real-time breakdown of an attack email highlighting typosquatted domains, artificial urgency, and destination URL mismatches.
3. **Deceptive Websites & Homograph Attacks**: Explains typosquatting, combosquatting, and how attackers misuse SSL certificates (`https` does not automatically mean safe).
4. **"Spot the Phish" Interactive Quiz**: Hands-on scenario challenge where users evaluate real-world emails and attachments, testing their skills with instantaneous feedback and scoring.
5. **Defensive Best Practices**: Practical safeguards including Multi-Factor Authentication (MFA), email authentication mechanisms (SPF, DKIM, DMARC), and out-of-band verification.

---

## 🚀 How to Run

No web server or dependencies required!

1. Clone or download this repository.
2. Open `index.html` in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
```bash
# Windows
start index.html

# Linux
xdg-open index.html

# macOS
open index.html
```
